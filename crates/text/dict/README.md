# Słowniki pisowni

- `pl_PL.*` – słownik SJP.PL (https://sjp.pl/slownik/ort/), wielolicencyjny (GPL, LGPL, MPL, Apache 2.0, CC BY 4.0) – zob. `README_pl.txt`. Przekodowany z ISO-8859-2 na UTF-8.
- `en_US.*` – SCOWL / Hunspell en_US (licencja w `README_en_US.txt`).

Źródło: repozytorium słowników LibreOffice (https://github.com/LibreOffice/dictionaries).
